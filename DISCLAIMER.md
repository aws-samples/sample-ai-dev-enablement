# Disclaimer

This repository is educational sample content. It describes practices and provides agent
skills that generate guidance for your own repositories.

Do not deploy anything from this repository to a production environment, or run it
against production or other critical data, without additional security testing and
review against your own quality control practices and standards. You are responsible for
testing, securing and optimizing anything you take from here before production use.

The agent skills in `skills/` instruct an AI agent to read a repository and write files
into it. Review what an agent proposes before you accept it, and run it against a branch
or a copy first.

Where a practice is attributed to a named company, product or report, the attribution is
to the public source linked next to it. Nothing here represents a commitment about any
product or roadmap.
